# Импорт своей музыки

Sonora умеет играть ваши файлы без стриминга — как «Local files» в Spotify.
Файлы копируются в папку приложения, поэтому доступны офлайн и не зависят от сети.

## 1. Подходящие форматы

| Формат | Расширения | Примечание |
|---|---|---|
| MP3 | `.mp3` | самый совместимый |
| FLAC | `.flac` | без потерь, теги и обложка поддерживаются |
| AAC/M4A | `.m4a`, `.aac` | iTunes/Apple Music (файлы без DRM) |
| Ogg Vorbis / Opus | `.ogg`, `.oga`, `.opus` | открытые кодеки |
| WAV | `.wav` | тегов обычно нет — заполнятся онлайн-метаданными |

Не подойдут: файлы с DRM (купленная музыка из стриминговых сервисов), битые
или недокачанные файлы, а также видеофайлы.

## 2. Как подготовить файлы

1. Разложите музыку в одну папку, например `Sonora Music/`.
2. Назовите файлы по шаблону **«Исполнитель - Название.mp3»**.
3. Заполните теги: `title`, `artist`, `album`, `year`, номер трека.
   Подойдёт любой редактор тегов:
   - **Mp3tag** (Windows) — массовое переименование и теги из имени файла;
   - **MusicBrainz Picard** — автоматическое определение релиза и обложки;
   - **foobar2000**, **Kid3**, **EasyTAG** — тоже работают.
4. Обложку лучше **вложить в тег** (`APIC`/`covr`): приложение покажет её без
   интернета. Если обложки нет, Sonora попробует найти её онлайн
   (iTunes, Deezer, Cover Art Archive).
5. Свои CD можно оцифровать в FLAC/MP3 через Exact Audio Copy, Whipper или
   `abcde` — теги и обложку они добавят сами.

### Пример структуры

```
Sonora Music/
├── Queen - Bohemian Rhapsody.mp3
├── Michael Jackson - Billie Jean.flac
├── Daft Punk - Get Lucky.m4a
└── Кино - Группа крови.opus
```

### Пример списка файлов для проверки

```
Queen - Bohemian Rhapsody.mp3      Queen / A Night at the Opera / 1975
Michael Jackson - Billie Jean.flac Michael Jackson / Thriller / 1982
Daft Punk - Get Lucky.m4a          Daft Punk / Random Access Memories / 2013
```

Если тегов нет, приложение попробует разобрать имя файла «Исполнитель - Название»
и подтянуть альбом, год, обложку и текст из MusicBrainz, iTunes, Deezer и LRCLIB.

## 3. Импорт в приложении

1. Главная → карточка **«Своя музыка файлами»**.
2. **«Выбрать файлы»** → отметьте одну или несколько песен (можно всю папку
   через «⋮ → Выбрать все»).
3. Файлы копируются в приватную папку приложения, библиотека пересканируется,
   треки появляются в **Медиатеке**.
4. Если включён автопоиск метаданных, обложки/альбом/текст подтянутся сами;
   прогресс виден в Настройках → «Обогатить метаданные сейчас».

**Инструкция внутри приложения:** та же карточка → кнопка **«Инструкция»**.

## 4. Где хранятся файлы и как их удалить

- Внутренняя папка приложения: `Android/data/app.sonora/files/…` (доступна без root
  через проводник с доступом к Android/data, в системных настройках — «Хранилище»).
- Удалить трек: долгое нажатие на трек в Медиатеке → удалить, либо удалить файл
  и нажать «Пересканировать».

## 5. Частые вопросы

**Можно ли импортировать плейлист `.m3u`?**
Да, но как **список треков**, а не как аудиофайлы: Настройки → «Импорт из других
платформ» → выберите `.m3u`/`.m3u8`. Sonora прочитает пути и названия, найдёт
совпадения в библиотеке и InnerTube и создаст плейлист. Сами файлы по ссылкам
из M3U не копируются — для этого используйте импорт аудиофайлов (раздел 3).

**Почему у трека нет обложки?**
В теге нет картинки, а онлайн-каталоги не нашли совпадение (редкий релиз или
нестандартное название). Поправьте теги и нажмите «Обогатить метаданные сейчас».

**Можно ли импортировать музыку с телефона, а не из файлов?**
Да: «Пересканировать» в Медиатеке находит всё, что лежит в папках `Music`,
`Download`, `Downloads` и в папке загрузок приложения.

**Это законно?**
Импортировать и слушать собственные файлы и списки треков — да. Sonora не
обходит DRM и не скачивает полные треки Spotify/SoundCloud. Сохранение из
InnerTube/YouTube предназначено для личного офлайн-доступа и может нарушать
условия сервиса; ответственность за использование лежит на пользователе.

## 6. Импорт плейлиста из другого сервиса

Это отдельный сценарий: переносится **список треков**, а не аудиофайлы.
Например, из Spotify, Apple Music или YouTube Music.

### 6.1. Пошагово

1. Получите файл со списком:
   - **Spotify** — CSV через Exportify или аналогичный экспорт;
   - **Apple Music** — CSV/JSON-экспорт;
   - **YouTube Music** — CSV или Google Takeout;
   - **вручную** — TXT/M3U, по строке `Артист — Название`.
2. В Sonora откройте **Настройки → Импорт из других платформ**.
3. Нажмите **«Импортировать плейлист из файла»** и выберите файл.
4. Дождитесь окончания поиска. Готовый плейлист появится в разделе
   **«Плейлисты»** с названием **«Импорт: имя файла»**.

Во время импорта в настройках показывается прогресс: сколько треков обработано,
сколько найдено и сколько пропущено. Кнопка «Скрыть» очищает итог.

### 6.2. Поддерживаемые форматы

| Формат | Расширения | Что читается |
|---|---|---|
| CSV / TSV | `.csv`, `.tsv`, `.txt` с разделителями | колонки названия, исполнителя, альбома, длительности, Video ID/URL |
| JSON | `.json` | Spotify (`items[].track`), Apple Music (`data[].attributes`), произвольные массивы объектов |
| M3U / M3U8 | `.m3u`, `.m3u8` | `#EXTINF` (длительность и «Исполнитель - Название») и ссылки |
| TXT | `.txt` | по строке `Артист — Название`, `Артист - Название` или просто название |

CSV-заголовки понимаются на русском и английском: `Track Name`, `Artist Name(s)`,
`Album Name`, `Duration (ms)`, `Video ID`; `Название`, `Исполнитель`, `Альбом`,
`Длительность`. Регистр и лишние символы в заголовках не важны. Значения с
запятыми можно брать в кавычки: `"Song, with comma"`.

### 6.3. Примеры файлов

**Spotify CSV (Exportify):**

```csv
Track Name,Artist Name(s),Album Name,Duration (ms),Video ID
Smells Like Teen Spirit,Nirvana,Nevermind,302000,
Bohemian Rhapsody,Queen,A Night at the Opera,354000,
```

**Spotify JSON (фрагмент экспорта):**

```json
{
  "items": [
    {
      "track": {
        "name": "Smells Like Teen Spirit",
        "artists": [{ "name": "Nirvana" }],
        "album": { "name": "Nevermind" },
        "duration_ms": 302000
      }
    }
  ]
}
```

**Apple Music JSON:**

```json
{
  "data": [
    {
      "type": "songs",
      "attributes": {
        "name": "Smells Like Teen Spirit",
        "artistName": "Nirvana",
        "albumName": "Nevermind",
        "durationInMillis": 301000
      }
    }
  ]
}
```

**M3U:**

```m3u
#EXTM3U
#EXTINF:302,Nirvana - Smells Like Teen Spirit
https://music.youtube.com/watch?v=ljUtuoFt-8c
#EXTINF:354,Queen - Bohemian Rhapsody
https://open.spotify.com/track/xyz
```

**TXT:**

```text
# мой список
Nirvana - Smells Like Teen Spirit
Queen — Bohemian Rhapsody
Just A Title
```

### 6.4. Как ищутся совпадения

Для каждой строки Sonora:

1. Ищет трек в **локальной библиотеке**. Совпадение считается надёжным при
   оценке не меньше 3:
   - точное название — 3 балла, частичное — 1;
   - точный исполнитель — 2 балла, частичное — 1;
   - разница длительности не больше 10 секунд — ещё 1 балл.
2. Если в файле есть **Video ID или ссылка YouTube**, трек создаётся сразу по
   этому id, без поиска.
3. Иначе ищет в **InnerTube** (первые 5 результатов) и выбирает лучший по той же
   оценке. Слишком слабые совпадения отбрасываются.
4. Дубликаты внутри файла удаляются по паре «название + исполнитель».

Локальные треки имеют приоритет: если песня уже есть на устройстве, онлайн-копия
не создаётся. Найденные онлайн-треки кэшируются в библиотеке и играются через
InnerTube.

### 6.5. Лимиты

| Параметр | Значение |
|---|---|
| Треков за один импорт | до **150** |
| Строк в файле | до **1 000** (лишние отбрасываются) |
| Размер файла | до **8 МБ** |
| Длина названия плейлиста | до 80 символов |

Ограничение в 150 треков связано с тем, что каждый неизвестный трек — отдельный
поисковый запрос к InnerTube. Большой плейлист лучше разбить на части.

### 6.6. Если импорт не сработал

| Симптом | Причина и решение |
|---|---|
| «В файле не найдено треков» | Не тот формат/колонки. Проверьте примеры выше; для Spotify используйте CSV Exportify |
| Найдено 0 из N | Названия сильно отличаются или нет сети. Упростите названия, уберите remaster/live-пометки |
| Найдено меньше, чем в файле | Часть треков отсутствует в локальной библиотеке и InnerTube; они пропущены |
| Плейлист создан, но треки не играют | Онлайн-трек не имеет Video ID и не резолвится; удалите его и импортируйте заново |
| Импорт идёт очень долго | До 150 сетевых запросов; дождитесь окончания или уменьшите файл |
| Ошибка чтения файла | Файл повреждён, защищён паролем или больше 8 МБ |
| Кириллица в CSV «кракозябрами» | Пересохраните файл в UTF-8 (Exportify и Apple обычно делают это сами) |

После импорта плейлист можно переименовать, удалить из него треки или добавить
новые — это обычный плейлист Sonora.

### 6.7. Приватность и правовая рамка

- Файл читается **локально**; Sonora не загружает его на сервер.
- В сеть уходят только поисковые запросы к InnerTube (название и исполнитель),
  как при обычном поиске.
- Импортируется список, а не аудио. Полные треки Spotify/SoundCloud не
  скачиваются; см. [LEGAL.md](LEGAL.md).
- Импорт библиотеки YouTube Music из Google Takeout описан отдельно в
  [TAKEOUT.md](TAKEOUT.md).
