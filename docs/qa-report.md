## Найденные и исправленные баги

1. **ANR PlaybackService при старте с виджета** — `Context.startForegroundService() did not then call Service.startForeground()`.
   Исправлено: `PendingIntent.getForegroundService` для кнопок виджета + временное boot-уведомление в `PlaybackService` до старта Media3.
2. **Фоновый старт FGS запрещён на Android 14** — broadcast-приёмник виджета получал `ForegroundServiceStartNotAllowedException`.
   Исправлено тем же PendingIntent-подходом; проверено реальным тапом по виджету.
3. **С «Обзора» нельзя вернуться на Главную нижним меню** — Home-вкладка была selected, а `navigate(HOME)` с restoreState возвращал «Обзор».
   Исправлено `popBackStack(Routes.HOME, false)` для вложенных маршрутов.

## Ограничения проверки

- Эмулятор один раз откатился к старому снапшоту; часть автоматизированных прогонов QA пришлось перезапускать, поэтому не все пункты закрыты повторным автоматическим прогоном — критичные проверки выше выполнены вручную после финальных фиксов.
- Автоподбор NoHiT на тестовой сети вернул `fail` (TSPU/сеть), это ожидаемое ограничение NoHiT, а не краш.
- Распознавание через AudD требует ключ; без ключа проверен локальный фолбэк и обработка тишины. Полная идентификация чужой песни через AudD не проверялась без ключа.

## Sonora 3.0.0 — проверка удаления WARP и NoHiT-only

- Сборка: **3.0.0** (ersionCode 39), Android 14 emulator, сеть без VPN.
- WARP/AWARP/relay: в манифесте **нет VpnService/BIND_VPN_SERVICE**, в UI нет
  разделов WARP/«Медиашлюз», в APK нет конфигов и AmneziaWG-движка.
- NoHiT: OkHttp ходит через `NoHiT.client()`; для Ktor/yt-dlp — локальный
  прокси; старые TCP-only конфиги мигрируют на SNI/TLS; автоподбор дополнен
  `TLS_16`/`TLS_32`.
- Поиск «Queen» без VPN: **25 результатов**, включая YouTube Music (через
  yt-dlp/NoHiT).
- Онлайн-трек без VPN: yt-dlp скачивает аудио через NoHiT в кэш, ExoPlayer
  играет локальный файл — `state=PLAYING` (position > 3 c), повторный запуск
  мгновенный из кэша.
- Нижнее меню/виджет/shuffle/волна/распознавание — без изменений с 2.3.0.
- Unit-тесты: 122 выполнено, 0 ошибок, 7 сетевых smoke-тестов пропущены в
  сети с DPI; lint без ошибок.

### Ограничение

- Первое онлайн-воспроизведение скачивает трек через yt-dlp (несколько секунд),
  затем играет из кэша; это плата за работу без VPN и без WARP.

## Sonora 3.3.0 — адаптивная частота 1–120 Гц

- `AdaptiveRefreshRate`: запрос максимума (≤120 Гц) на старт/касание/скролл,
  сброс в системный режим через 700 мс после жеста — LTPO может уходить в 1 Гц.
- DisplayListener обновляет максимум при смене режима дисплея; наружу настроек нет.
- Проверено на эмуляторе (60 Гц): `RefreshRate: display=0 supported=[60.0]
  max=60.0 -> request up to 60.0 Hz`; `frameRateOverride` для uid приложения
  появляется на жест и снимается после отпускания.
- 120 Гц не проверить на эмуляторе (нет такого режима), логика ограничена 120 Гц
  и использует системный preferred refresh rate.
