# Что можно и чего нельзя — коротко и по делу

Этот документ объясняет, как Sonora работает с сервисами и где проходят границы.
Он не заменяет лицензии и законы и не является юридической консультацией.

## 1. Как устроена Sonora

- **Своя музыка** (локальные файлы, Bandcamp, CD-рипы) играет полностью и офлайн.
- **Свободные каталоги** (Internet Archive, Jamendo) можно искать, играть и скачивать:
  авторы разрешили это лицензиями CC/PD.
- **YouTube Music** работает через InnerTube — недокументированный протокол, который
  используют Metrolist и другие открытые клиенты. Sonora играет поток, умеет сохранять
  его в приватную папку для личного офлайна и не блокирует рекламу.
- **Spotify** отдаёт метаданные и 30-секундные превью (если приложение их получило);
  полные треки открываются в клиенте Spotify.
- **SoundCloud** — поиск и метаданные по официальному `client_id`, воспроизведение
  разрешённых треков, переход в приложение.

## 2. По платформам

### YouTube / YouTube Music

| Что Sonora делает | Что не делает |
|---|---|
| Поиск, плейлисты, очередь, тексты, аудиопоток через InnerTube | Не обходит DRM |
| Скачивает поток в приватную папку приложения для личного офлайна | Не распространяет файлы и не выкладывает их в сеть |
| Импорт публичного плейлиста по ссылке | Не блокирует рекламу в веб-плеере |
| Импорт списка треков из CSV/JSON/M3U/TXT | Не скачивает полные треки Spotify/SoundCloud |
| Импорт своей библиотеки из Google Takeout | Не выдаёт себя за официальный клиент YouTube |
| Встроенный `music.youtube.com` в WebView для входа в аккаунт | — |

Скачивание с YouTube нарушает условия сервиса (ToS), даже если файл остаётся у
пользователя. Sonora не предоставляет публичный доступ к таким файлам; ответственность
за использование лежит на пользователе и распространителе сборки.

InnerTube — неофициальный протокол. YouTube может изменить его в любой момент;
это риск нестабильности, а не гарантия работы. Условия YouTube и законы об обходе
технических средств защиты (ст. 1299 ГК РФ, DMCA §1201, Directive 2001/29/EC)
остаются ответственностью распространителя сборки.

### Spotify

| Можно | Нельзя |
|---|---|
| OAuth-вход, чтение своих плейлистов и «Мне нравится» (`user-library-read`, `playlist-read-private`) | Играть полные треки: у Web API нет аудио-endpoint'а, поток защищён DRM |
| Поиск, метаданные, обложки | Скачивать полные треки: офлайн-скачивание есть только в клиенте Spotify для Premium |
| 30-секундные превью — **если** Spotify их выдал приложению — и их сохранение в приватную папку для личного использования | Обходить DRM (Widevine/EME) |
| Управление клиентом Spotify (App Remote) при Premium | Использовать недокументированные внутренние API |

С 27.11.2024 `preview_url` убран из мульти-ответов для новых приложений, а с февраля 2026
Development Mode требует Spotify Premium и ограничен 5 пользователями.
Источники: [Web API changes 27.11.2024](https://developer.spotify.com/blog/2024-11-27-changes-to-the-web-api),
[Developer Access 06.02.2026](https://developer.spotify.com/blog/2026-02-06-update-on-developer-access-and-platform-security),
[Web Playback SDK](https://developer.spotify.com/documentation/web-playback-sdk).

### SoundCloud

| Можно | Нельзя |
|---|---|
| Поиск, метаданные, `resolve` по ссылке (с официальным `client_id`) | Сохранять файлы, делать офлайн-кэш |
| Стриминг `stream_url` с обязательной атрибуцией | SoundCloud Go+ через API без соглашения |
| Переход в приложение SoundCloud | Объединять SoundCloud с контентом других сервисов в одном опыте воспроизведения |

Регистрация нового API-приложения требует **Artist Pro**; клиенты считаются confidential,
поэтому `client_secret` нельзя хранить в APK — нужен сервер.
Источники: [API Terms of Use](https://developers.soundcloud.com/docs/api/terms-of-use),
[Get an API key](https://developers.soundcloud.com/docs/api/register-app).

## 3. Свободная музыка

- **Internet Archive** — условия указаны в метаданных айтема (`licenseurl`/`rights`);
  приложение показывает лицензию у каждого трека.
- **Jamendo** — только треки с `audiodownload_allowed = true`; остальные не показываются.
- Требование атрибуции (автор, ссылка, лицензия) сохраняется в `Track.extra`.

## 4. Метаданные и тексты

MusicBrainz и Cover Art Archive — CC0/CC BY-NC-SA, iTunes/Deezer/TheAudioDB/Wikipedia —
публичные каталоги со своими условиями (проверьте их для коммерческого использования),
LRCLIB — общественная база текстов. Тексты песен, обложки и фотографии — объекты
авторского права: Sonora показывает их для личного некоммерческого использования
и не публикует.
