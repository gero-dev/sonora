# Импорт библиотеки YouTube Music из Google Takeout

Состояние на **26.10.2026** (v0.4.0). Модуль читает **Google Takeout** пользователя
(CSV или ZIP) и переносит метаданные сохранённых треков и плейлистов YouTube Music
в локальную библиотеку Sonora. Без OAuth, API-ключей и InnerTube: это просто файл,
который Google отдаёт владельцу аккаунта.

Код: `app/src/main/java/app/sonora/data/import/TakeoutImporter.kt`
(создаётся в `AppGraph.takeout`, вызывается из `MainViewModel.importTakeout`).

## Зачем это нужно

Takeout — официальный способ выгрузить свои данные. Sonora берёт из него только
метаданные (название, исполнитель, альбом, длительность, videoId); аудио не
скачивается: `uri = null`, `playable/downloadAllowed = false`, playback — deep link.

## Как сделать экспорт

1. Открыть <https://takeout.google.com/>, **Deselect all**, отметить
   **YouTube и YouTube Music**.
2. **All YouTube data included** → снять всё, отметить **playlists**
   (и **music (library and uploads)** — сохранённые треки).
3. **Next step** → формат **.zip**, экспорт один раз → **Create export**.
4. Скачать архив по ссылке из письма (живёт неделю); в Sonora выбрать `.zip`/`.csv`.

## Поддерживаемые файлы

- **ZIP** из Takeout: разбираются все вложенные `*.csv` (регистр расширения не важен),
  результаты объединяются; служебные CSV без названий пропускаются.
- **Один CSV** (например `music-library-songs.csv`) или ZIP; реальный формат:
  `Video ID,Song Title,Album Title,Artist Name 1`.
- Сторонние CSV с понятными заголовками (`title,artist,album,duration,playlist`).
- CSV **без заголовка**: позиционная раскладка `title=0, artist=1`.

## Что попадает в библиотеку

| Колонка CSV | Поле `Track` |
|---|---|
| Song Title / Title / Name / Track / Song / Название | `title` (обязательно) |
| Artist / Artist Name 1 / Channel Title / Исполнитель | `artist` (fallback «YouTube») |
| Album / Album Title / Альбом | `album` (может быть пустым) |
| Video ID / ID | `videoId` → `id = youtube:<videoId>` |
| Duration / Duration (seconds) / Длительность | `durationMs` (секунды или ISO-8601 `PT3M45S`) |
| Playlist / Playlist Title / Playlist Name / Плейлист | имя плейлиста |

- Если videoId не 11-символьный base64url — `id = youtube:import:<hex(hash)>`,
  а `deepLink` ведёт на поиск `AppLinks.youtubeMusicSearch("artist title")`.
- `extra["importedFrom"] = "takeout"`, `extra["videoId"]` — при валидном id.
- Дубликаты склеиваются по `id`; порядок строк сохраняется.
- Плейлисты: группировка по колонке плейлиста, `id = takeout:<slug>`,
  `source = YOUTUBE`, `editable = false`, до 200 штук.

## Лимиты и предупреждения

- **200 000 строк** всего → «Достигнут лимит 200 000 строк».
- **10 000 треков** → «Достигнут лимит 10 000 треков» (импорт обрезается).
- **200 плейлистов** → импортируются первые 200.
- Пропущенные строки/файлы: «Пропущено строк: N»,
  «Пропущено файлов без колонки названия: N».
- Ошибки чтения: «Не удалось прочитать файл: …»; импорт не падает.
- Если ничего не найдено — «В файле не нашлось треков…».

## Ограничения

- Takeout-плейлисты из папки `playlists/` содержат только `Video ID` и timestamp,
  без названий, поэтому пропускаются: плейлисты импортируются, только если в CSV
  есть колонка плейлиста и названия треков.
- В `music-library-songs.csv` часто нет длительности и обложек — они остаются 0/null.
- История просмотров, подписки и поиски не импортируются (это не библиотека).
- Повторный импорт обновляет треки/плейлисты с теми же id, дублей не создаёт.

## Приватность

Всё происходит **локально**: файл читается через SAF, ни одного сетевого запроса,
ничего не загружается на серверы. Импортированные метаданные лежат в JSON
приложения (`library_tracks.json`, `library_playlists.json`); удалить их можно
очисткой данных приложения. Треки с Video ID играются через InnerTube;
без Video ID остаётся deep link в YouTube Music. Аудио при импорте не
скачивается, но найденный трек можно потом сохранить обычной кнопкой
«Скачать» — см. [DOWNLOADS.md](DOWNLOADS.md).

## Типовые сбои

| Симптом | Причина | Поведение |
|---|---|---|
| «В файле не нашлось треков» | выбран не тот CSV или нет колонки названия | понятное предупреждение, ничего не импортировано |
| «Пропущено файлов без колонки названия: N» | в ZIP лежат subscriptions/history/плейлисты-таймстемпы | файлы пропущены, треки из остальных импортированы |
| «Не удалось прочитать файл: …» | SAF отказал в доступе или битый ZIP | пустой результат + предупреждение, UI не падает |
| Импорт «завис» на большом архиве | очень большой ZIP, лимит 200 000 строк | чтение останавливается, возвращается частичный результат |
| Исполнитель «YouTube» у всех треков | в CSV нет колонки исполнителя | ожидаемый fallback |
| Трек открывается поиском, а не видео | битый/отсутствующий Video ID | deep link на поиск по «artist title» |
