# Как помочь проекту

Спасибо, что заглянули! Sonora — учебно-практический открытый проект. Ниже — как собрать,
что можно улучшить и как оформить изменение.

## Сборка

Требования: **JDK 21**, Android SDK 37 (через Android Studio или `sdkmanager`).

```bash
git clone <repo-url>
cd sonora
./gradlew :app:assembleDebug        # APK: app/build/outputs/apk/debug/
./gradlew :app:lintDebug            # статический анализ
```

Windows: `gradlew.bat`. Если путь к проекту содержит кириллицу, в `gradle.properties`
уже стоит `android.overridePathCheck=true`.

## Что приветствуется

- Исправления багов (особенно UI на маленьких экранах и в светлой теме).
- Новые раскладки виджета, улучшение доступности (contentDescription, TalkBack).
- Тесты: unit для `MetadataService`/`TakeoutImporter`/CSV-парсера, Compose UI-тесты.
- Локализация (сейчас строки на русском прямо в коде — вынос в `strings.xml` тоже вклад).
- Документация: скриншоты, гайды, исправление неточностей.

## Ограничения проекта (важно)

YouTube Music в Sonora работает через InnerTube и InnerTubeX (GPL-3.0) — как Metrolist.
Кнопка «Скачать» сохраняет доступный поток (InnerTube, прямые URL, открытые каталоги)
в приватную папку для личного офлайн-доступа. Обход DRM, скачивание из Spotify/SoundCloud
и блокировка рекламы не реализуются; PR с DRM-обходом не принимаются.

## Процесс

1. Поищите существующий Issue; если его нет — создайте по шаблону.
2. Для крупных изменений сначала обсудите в Issue (иначе PR может не подойти по архитектуре).
3. Форк → ветка `feature/<короткое-имя>` или `fix/<короткое-имя>`.
4. Коммиты в стиле [Conventional Commits](https://www.conventionalcommits.org/ru/):
   `feat(widget): раскладка 2x2`, `fix(player): свайп не закрывал экран`, `docs: ...`.
5. PR в `main`: опишите, что и зачем, приложите скриншот для UI-изменений.
6. CI должен быть зелёным (`assembleDebug` + `lintDebug`).

## Стиль кода

- Kotlin, отступ 4 пробела, `kotlin.code.style=official`.
- Идентификаторы — английские, комментарии и UI-тексты — русские.
- Без новых зависимостей без обсуждения в Issue.
- Compose: Material 3, никаких `ExperimentalMaterial3Api` без необходимости.
- Не добавляйте ключи, токены и персональные данные в репозиторий.

## Лицензия вклада

Отправляя PR, вы соглашаетесь, что ваш код распространяется под лицензией проекта (MIT).
