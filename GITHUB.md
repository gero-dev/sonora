## 2. Релиз **v1.8.0**

**Тег:** `v1.8.0` · **Заголовок:** `Sonora 1.8.0 — вся медиатека одной кнопкой вперемешку и починенное переключение вперёд`

### Release notes

```markdown
## Sonora 1.8.0

### Вся медиатека с одной кнопки

- В шапке «Медиатеки» — большая кнопка **«Слушать всю медиатеку»**: вся
  фонотека (локальные файлы + сохранённые из стриминга) запускается одним
  нажатием **вперемешку**, как «Понравившиеся» в Spotify. Shuffle включается
  автоматически, подпись показывает число треков.
- Кнопка доступна на всех вкладках медиатеки и неактивна, если треков нет.

### Исправлено переключение треков вперёд

- «Следующий трек» больше не залипает: работает сразу после запуска очереди
  (даже если Media3 ещё не пересчитал timeline), в конце очереди (треки
  докупаются перед переходом) и на паузе/буферизации — воспроизведение
  продолжается.
- Если очередь кончилась и докупать нечего, выполняется переход по
  абсолютному индексу очереди.

### Включает автопилот стриминга из 1.7.0

- Приложение само проверяет прямой InnerTube, yt-dlp, медиашлюз и собственный
  WARP, выбирает рабочий способ и переключается при 403. В РФ без VPN оно
  само поднимает свой WARP-туннель (подключение 1–2 с) и играет через yt-dlp.

### Технически

- versionCode **30**, versionName **1.8.0**, targetSdk 34, minSdk 26.
- `playLibraryShuffled()`, `LibraryPlayAllRow`, усиленный `next()`.
- 59 unit-тестов, lint без ошибок.
```

```bash

```

сеть → Автопилот» (включён по умолчанию).

## 4. Важные оговорки

- **InnerTube и yt-dlp** — неофициальные клиенты YouTube Music; YouTube может
  изменить протокол. Приложение не связано с Google/YouTube.
- **Автопилот** не обходит блокировку сам по себе: он подбирает рабочий
  транспорт. Если провайдер блокирует и WARP-эндпоинты, приложение честно
  покажет это.
- **WARP** — обычный WireGuard-туннель только для трафика Sonora; авторегистрация
  создаёт анонимный профиль Cloudflare. Перед публичной сборкой удалите
  `app/src/main/assets/warp/`.
- **Лицензия GPL-3.0** — см. `THIRD-PARTY-NOTICES.md`.
- Скачивание с YouTube нарушает условия сервиса; ответственность — на
  пользователе. DRM не обходится.
