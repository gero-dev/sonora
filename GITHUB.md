## 2. Релиз **v1.6.0**

**Тег:** `v1.6.0` · **Заголовок:** `Sonora 1.6.0 — стриминг в РФ без VPN/WARP, медиатека в стиле Spotify и быстрая фонотека`

### Release notes

```markdown
## Sonora 1.6.0

### Стриминг в РФ без VPN и WARP

- **yt-dlp обновляется сам**: встроенная сборка 2025.11.12 устаревает за недели
  и даёт 403. Приложение качает свежий zipapp напрямую с GitHub Releases (без
  лимита api.github.com), проверяет версию, ставит и откатывается при ошибке.
  Авто — раз в сутки, вручную — кнопкой. Проверено: 2025.11.12 → 2026.10.26.
- **Перебор клиентов YouTube и IPv4/IPv6**: default/tv_simply → tv/android_vr →
  web_safari → ios/mweb → android/web; удачный набор запоминается.
- **Проверка ссылки перед воспроизведением**: Range-запрос, в плеер попадает
  только поток, который реально отвечает 200/206 аудио-байтами.
- **Медиашлюз без VPN**: Invidious/Piped с автопоиском, health-check, failover,
  кэшем и своим списком зеркал в настройках. Новый источник «Шлюз».
- **«Проверить поток»**: покомпонентный отчёт — прямой InnerTube, yt-dlp,
  медиашлюз — с реальными кодами и подсказками.
- Новый документ `docs/STREAMING-RF.md`: что блокируется, почему флаги не
  обходят блокировку IP, замеры зеркал из РФ, честные ограничения.

### Медиатека в стиле Spotify

- Крупная шапка «Медиатека» с градиентом и сводкой, чипы «Все / Плейлисты /
  Альбомы / Исполнители / Треки / Избранное / YouTube».
- **Плейлисты карточками**: коллаж до 4 обложек, жирное название, «N треков» и
  круглая кнопка **Play прямо на обложке** — запуск без открытия экрана.
  Плитка «Создать плейлист», прежние действия по долгому нажатию.
- Альбомы и исполнители сетками: скруглённые обложки и круглые аватары с Play,
  подписи «исполнитель · год».
- Плотные строки треков, обновлённый мини-плеер с тонким прогрессом и круглой
  кнопкой, более плотная типографика — в 12 акцентных палитрах Sonora.

### Быстрая фонотека

- **Инкрементальное сканирование** с дисковым кэшем сигнатур (путь + размер +
  дата изменения): повторный скан читает только изменённые файлы.
- Один MediaStore-запрос с минимальной проекцией; параллельное извлечение
  метаданных (4 потока), обложки не грузятся зря.
- **Быстрый поиск**: токен-индекс на версию библиотеки вместо нормализации
  всей фонотеки на каждое нажатие; прежнее ранжирование сохранено.
- Timing-логи `LibraryPerf` и 29 новых JVM-тестов.

### Технически

- versionCode **28**, versionName **1.6.0**, targetSdk 34, minSdk 26.
- APK **~224 МБ** (Python-рантайм yt-dlp + ffmpeg), debug-подпись.
- `StreamProbe`, `RelayGateway`, `YtDlpResolver` (прямое обновление zipapp),
  `InnerTubeStreams` (цепочка InnerTubeX → InnerTube → yt-dlp → шлюз),
  `ScanCache`, `LibrarySearchIndex`.

### Проверка

- `assembleDebug` — BUILD SUCCESSFUL;
- `testDebugUnitTest` — 59 тестов, 0 ошибок;
- `lintDebug` — без ошибок;
- на эмуляторе Android 14: обновление yt-dlp 2025.11.12 → 2026.10.26,
  «Проверить поток» → OK, медиатека/плейлисты отрисованы.
```

```bash

```

Или скопировать APK на телефон и открыть (разрешить установку из неизвестных
источников). После установки: «Настройки → Поток и сеть → Обновить yt-dlp
сейчас», затем «Проверить поток».

## 4. Важные оговорки

- **InnerTube и yt-dlp** — неофициальные клиенты YouTube Music; YouTube может
  изменить протокол. Приложение не связано с Google/YouTube.
- **Стриминг без VPN/WARP** работает, пока провайдер не блокирует медиа-IP
  полностью: клиентские флаги не обходят сетевую блокировку. Публичные зеркала —
  best-effort; надёжный вариант — свой релей (см. STREAMING-RF.md).
- **WARP** — обычный WireGuard-туннель только для трафика Sonora; встроенные
  конфиги лежат в APK и предназначены для личного использования. Перед
  публичной сборкой удалите `app/src/main/assets/warp/`.
- **Лицензия GPL-3.0** (совместима с InnerTubeX GPL-3.0) — см.
  `THIRD-PARTY-NOTICES.md`.
- Скачивание с YouTube нарушает условия сервиса; ответственность — на
  пользователе. DRM не обходится.
